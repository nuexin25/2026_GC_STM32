# nx_car 本地数据看板 —— 网站功能说明

> 版本：v1.0　日期：2026-09-14

## 1. 项目简介与用途

本网站是 nx_car 智能搬运机器人的**纯本地数据看板**，用于把 STM32 主控的
全部运行数据（调试日志、IMU、电机、任务码、树莓派视觉数据、任务阶段等）
通过串口上传到电脑，并以中文网页的形式实时可视化展示。

**特点**：
- 纯本地运行，不部署公网、不涉及树莓派、不占用 USART1（USART1 保留给比赛视觉通信）
- 单机单进程，一条命令启动
- 数据全部落 SQLite，支持按时间范围历史回放
- 网页顶部可下拉选择 COM 口，硬件换 COM 号无需改配置

## 2. 架构示意

```
STM32(UART5, 115200 调试串口)
        │
        │ 串口逐行读
        ▼
[后台串口采集线程]  collector.py
        │  解析（JSON 结构化 / 文本日志 [TAG]）
        ├──────────────► [SQLite 历史库]  db.py  (data/telemetry.db)
        │
        └──────────────► [WebSocket 广播]  app.py
                              │
                              ▼
                      [浏览器实时显示]  static/ (index.html + app.js + Chart.js)
```

- 串口读取在**独立后台线程**，不阻塞网页响应
- 采集到数据后：**存 SQLite + WebSocket 广播**，两条链路同时进行
- 整个程序单进程运行，`python app.py` 一条命令启动

## 3. 环境依赖与安装步骤

**环境要求**：Python 3.10+

**安装依赖**：

```bash
cd web_dashboard
pip install -r requirements.txt
```

依赖清单（requirements.txt）：

| 包 | 用途 |
|---|---|
| Flask | Web 框架 |
| flask-sock | 原生 WebSocket（比 flask-socketio 更轻量，无额外协议依赖） |
| simple-websocket | flask-sock 底层依赖 |
| pyserial | 串口读写 |

> Chart.js 已本地化在 `static/chart.min.js`，无需联网加载。

## 4. 启动方法

```bash
cd web_dashboard
python app.py
```

启动成功后，浏览器访问：

```
http://127.0.0.1:5000
```

（端口在 `config.py` 中 `WEB_PORT` 配置，默认 5000）

## 5. 配置说明（config.py）

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `SERIAL_PORT` | `"auto"` | 串口号。Windows 如 `"COM3"`；`"auto"` 自动探测第一个可用串口。也可在网页顶部下拉选择，无需改此配置 |
| `SERIAL_BAUD` | `115200` | 波特率，与 STM32 UART5 一致 |
| `SERIAL_TIMEOUT` | `0.1` | 串口读取超时（秒） |
| `RECONNECT_INTERVAL` | `2.0` | 串口断开后重连间隔（秒） |
| `WEB_HOST` | `"127.0.0.1"` | Web 监听地址（只本机） |
| `WEB_PORT` | `5000` | Web 端口 |
| `DB_PATH` | `data/telemetry.db` | SQLite 单文件路径 |
| `RETENTION_DAYS` | `0` | 数据保留天数，0=永久保留 |
| `CHART_MAX_POINTS` | `300` | 实时曲线保留点数 |

## 6. 五个标签页功能介绍

### 标签页 1：状态概览
- **系统状态**：运行时间、心跳、任务码、当前阶段（STG）
- **最新位姿**：X/Y 坐标、Yaw 角
- **电机状态**：4 轮（前左/前右/后左/后右）在线状态与转速卡片
- **视觉数据**：最新一条视觉帧摘要（OBS/PLA/NAV/BOX/TRN）

### 标签页 2：实时数据
- IMU Yaw 角实时曲线
- 定位 XY 轨迹图（2D 场地俯视散点）
- 四轮转速实时曲线
- 视觉数据最新卡片

> 曲线实时滚动更新，保留最近 300 点。

### 标签页 3：历史回放
- 选择数据类型（IMU/定位/电机/视觉/任务码/阶段）
- 选择时间范围（开始/结束时间）
- 点击「加载」绘制历史曲线（支持视觉子类型筛选）
- 点击「导出 CSV」导出当前视图数据

### 标签页 4：日志
- 实时日志流（自动滚动，可暂停/清空）
- Tag 过滤下拉（多选）
- 关键字搜索
- 历史日志按时间范围查询

### 标签页 5：参数（预留）
- 展示赛题参数占位列表（灰色，标注「暂未开放」）
- 本阶段不实现实际下发

## 7. 数据上报协议说明

采集器逐行解析串口数据，支持两种格式：

### 7.1 JSON 结构化行

每行一个 JSON 对象，通用格式 `{"t":"类型", ...}`。时间戳 `ts` 由采集器
收到时打本机时间（毫秒），不依赖 STM32 时钟。

| 类型 `t` | 字段 | 说明 |
|---|---|---|
| `log` | `tag`,`msg` | 通用日志 |
| `imu` | `yaw` | IMU yaw 角（deg） |
| `pose` | `x`,`y`,`yaw` | 车体位姿 |
| `motor` | `addr`,`rpm`,`pulse`,`state` | 电机（addr=1~4） |
| `task` | `code`,`valid` | 任务码 |
| `vision` | `sub`, 各字段 | 视觉数据（见下表） |
| `stage` | `id`,`name`,`code` | 任务阶段 |

**视觉数据（vision）各子类型字段**：

| `sub` | 字段 |
|---|---|
| `OBS` | `a`(方位角) `d`(距离) `side`(绕行) `clear`(安全) |
| `TRN` | `c1..c3`(颜色) `a1..a3`(角度) |
| `PLA` | `ring` `dx` `dy` `conf` |
| `NAV` | `x` `y` `yaw` `conf` |
| `BOX` | `has` `color` |

### 7.2 兼容纯文本日志

非 JSON 的行，用正则提取 `[TAG]` 和正文：

```
输入：  [CAN] addr=1 ok
输出：  {"t":"log","tag":"CAN","msg":"addr=1 ok"}
```

无法提取 tag 的行，tag 置 `RAW`，msg 为整行原文。

### 7.3 存储字段

所有类型统一存 SQLite，字段：`id`、`ts`（毫秒）、`type`、`tag`、`sub`、
`payload`（JSON 原文）。绘图时按 `type`/`tag`/`sub` 查询。

## 8. COM 口选择

网页顶部导航栏有一个「串口」下拉框：

- **自动探测**（默认）：按 `config.py` 的 `SERIAL_PORT` 自动探测
- **选择具体 COM 口**：硬件换 USB 口导致 COM 号变化时，在下拉框选择新
  COM 口即可，无需修改 `config.py` 或重启程序

下拉列表每 3 秒自动刷新，支持 COM 口热插拔。选择后立即生效，串口断开
会自动重连到所选端口。

## 9. 历史回放操作方法

1. 进入「历史回放」标签页
2. 选择数据类型（下拉）
3. 选择时间范围（开始/结束时间，默认最近 1 分钟）
4. 点击「加载」→ 下方绘制历史曲线
5. 可选：点击「导出 CSV」导出当前视图数据

## 10. 常见问题

| 问题 | 排查方法 |
|---|---|
| 串口打不开 | 看顶部「串口」下拉是否有可选 COM 口；Windows 设备管理器看 COM 号；确认串口未被其它程序占用 |
| 网页无数据 | 看顶部「数据源」状态：显示「串口」但无数据则检查接线/波特率；显示「未连接」则检查串口是否被占用或未接 |
| 端口占用 | 修改 `config.py` 中 `WEB_PORT` 为其它端口（如 5001） |
| 日志乱码 | 确认串口波特率 115200，与 STM32 UART5 一致 |
| 页面图表空白 | 确认 `static/chart.min.js` 存在（已本地化，无需联网） |
| WebSocket 断开 | 网页会自动重连，无需手动操作 |
